ELHAKY FINANCE - iPhone Read-Only Viewer

Upload index.html to the ROOT of https://github.com/elhaky-egp/Elhaky-iPhone-Viewer (GitHub Pages).
This is not the Mac repository. Do not upload financial JSON data to GitHub.

Features: OneDrive read-only connection; Dashboard; Transactions; 12-month forecast; Reports with multi-select years/groups/categories, searchable options and text search; drilldown; Groups and Categories browsing/search; Arabic/English; white income/red expenses.

No edit/delete/add actions. The iPhone reflects the latest read-only snapshot published by the Mac app to OneDrive; it cannot display Mac-only data missing from that snapshot.

Validation: JavaScript syntax checked only. OneDrive authentication and iPhone Safari not runtime tested.
